# PWA 驗證紀錄

日期：2026-09-08。首版提供安裝與離線，不保存文章；所有工具分頁／獨立視窗關閉後才套用新版。

## 自動化驗證

- `npm test`：既有轉換與介面測試，加上 PWA 安裝事件、拒絕／不支援、首次啟用、等待更新、更新失敗、網路恢復、節流及清理測試。
- `npm run build`：Vite 建置及 Workbox 產生 Service Worker，快取 9 個必要檔案（約 343 KB，未壓縮，不含 Service Worker 本身）。不完整／超量資源會讓建置失敗。
- `npm run test:pwa`：macOS 上 Playwright Chromium 153 的真實 Service Worker 測試；使用暫存 HTTP 伺服器的 A／B／C 三版本，不操作正式站。

已驗證情境：

| 情境 | 結果 |
| --- | --- |
| 首次未快取且斷網 | 無法開啟，不誤稱可離線 |
| 快取完成後關閉、斷網重新開啟 | 根目錄、入口頁及查詢參數可用 |
| 三款上色、HTML／原始碼複製與下載 | 通過；實際讀取瀏覽器剪貼簿及下載檔，未使用替身 |
| 外部圖片斷網 | 圖片失敗不影響轉換、上色、複製及下載；圖片不加入程式快取 |
| 未知路徑 | 不以離線首頁遮蔽錯誤 |
| 兩個 A 版分頁開啟時下載 B | 兩份原稿保持原樣；只關閉一頁仍等待，全部關閉後 B 才啟用 |
| C 版必要資源回傳 503 | 安裝失敗、原稿不變；B 仍能斷網重開 |
| 清除網站資料後斷網 | 無法重新開啟，必須重新連線 |
| 安裝資訊 | Chromium 解析 manifest 無錯誤；agent-browser 觀察到真實「安裝」入口 |
| 1280px／390px、深淺主題 | 包含可見安裝按鈕的配置，無整頁橫向溢出 |

瀏覽器測試已納入 GitHub Actions，測試截圖預設寫至系統暫存目錄 `baha-pwa-evidence`。複製成功僅代表瀏覽器剪貼簿，不代表巴哈貼上結果。

## 尚未驗證

- 桌面作業系統完成安裝後，由應用程式啟動器開啟的獨立視窗。
- Android Chrome 與 iOS Safari 實機安裝、主畫面啟動及離線流程；390px 測試不是手機實機驗證。
- 不保證瀏覽器永久保留快取；使用者清除資料或瀏覽器回收儲存空間後需重新連線。

## 發布檢查

發布時須確認對應提交的 GitHub Actions 成功，以及正式站首頁、manifest、圖示與 `sw.js` 回應，另以全新瀏覽器環境確認快取及斷網重開。回退須重新建置並部署，保留相同的 `sw.js` 更新網址。
