## 本輪整合輸出驗證

使用者原有回覆編輯器確認為 `[div]\n[/div]` 空白內容後，填入新版轉換器實際生成的緊湊原始碼：兩層引用、3×3 左中右對齊表格（含空白格）、3/4 文字編號及 code／空白行／end。

- 編輯區及文章預覽的可及性快照保留表格列、儲存格、兩層引用和所有文字。
- 電腦與手機文章預覽截圖均可見表頭與資料左／中／右對齊，空白格保留，編號與 code 空白行正常。
- 本輪 locator evaluate 持續逾時，未取得 computed style 與精確尺寸；不得將這次目視結果寫成 DOM 尺寸量測通過。
- 完成後關閉預覽並還原空白原始碼，保留使用者編輯器分頁。沒有發布、備份、修改既有貼文或寄信。
- 本輪富文字貼到巴哈後的結果尚未驗證；本機雙 clipboard payload 測試不能代替人工貼上。

## 標題與字級：使用者附件視覺證據

日期：2026-09-08。來源為使用者在本次對話提供的原始碼與「參考預覽更新技能」附件，頁面為上述回覆編輯器。截圖顯示工具列、回覆編輯區及簽名檔選單，屬於**所見即所得編輯區**，未顯示電腦／手機文章預覽對話框。本次僅比對附件，沒有重新操作草稿或量測 computed style；不將截圖像素換算為 CSS 字級。

| 原始碼與文字 | 附件可見效果 |
| --- | --- |
| `[h1]0 h1標[/h1]`、`[h2]1 大標[/h2]` | 兩者視覺大小相近，均為粗體大標題 |
| `[h3]2 中標[/h3]` | 小於 h1／h2，粗體 |
| `[h4]3 小標[/h4]` | 小於 h3，粗體 |
| `[quote]4 引文[/quote]` | 灰色文字，左側豎線與縮排，字級與段落相近 |
| `[div]5 段落[/div]` | 一般段落基準 |
| `[div][size=6]6 特大[/size][/div]` | 本組 size 最大，與大標題相近，但未呈現相同粗體 |
| `[div][size=5]7 很大[/size][/div]` | 小於 size 6、大於 size 4 |
| `[div][size=4]8 大[/size][/div]` | 大於一般段落 |
| `[div][size=3]9 中[/size][/div]` | 與一般段落視覺大小相近 |
| `[div][size=2]10 小[/size][/div]` | 小於一般段落 |

上表為相對視覺觀察，並非字級等值映射；粗體、字型與縮放會影響外觀。既有文章預覽曾量得 h1／h2 相同大小（見前表），但不能將其 px 數字套到本次編輯區，也不能由此推定 h4 或 size 2–6 的精確 px。此次未涵蓋 size 1／7，未新增其大小結論。標題的層級、粗體和段落間距不能只用 size 的近似大小取代。

使用者原始碼在 size 4 與 size 3 之間寫成 `[/div][` 加實體換行再接 `div]`；上表僅為對照而正規化為完整 `[div]`。附件不足以證明平台正式支援標記名稱內換行，不把此寫法當範本；生成輸出仍使用完整標記且不插入美化 LF。若需重現原始貼上行為，應保留該差異另測。
