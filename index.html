    支援六級標題與常用 Markdown／GFM 語法
    Markdown 語法 處理方式 備註
    六級標題（含 Setext） 一至三級 → [h2]／[h3]／[h4]；四至六級 → [div][b]…[/b][/div] HTML 保留 h1–h6；巴哈深層標題合併外觀並提醒，不新增編號
    段落、換行 逐行 [div]，段落間保留空白區塊 保留可見換行；生成標記間不插入美化換行
    粗體、斜體、刪除線 [b]、[i]、[s] 保持正確巢狀
    清單、工作清單 有序／無序與巢狀清單、☐／☑ 非 1 起始改為文字編號與手動縮排；自動折行不保證對齊
    表格 [table]，保留欄列及左／中／右對齊 本工具 HTML 可局部捲動；巴哈手機版仍可能溢出
    分隔線 轉成 [hr] 依輸入保留，不自行增加
    連結、圖片 [url=…]、[img=…] 工具限 HTTP(S)；已觀察公開貼文圖片，富文字貼上仍待確認
    引用 [quote]，保留多段、巢狀及內含清單 已有正式貼文驗證
    行內程式碼 保留文字，移除 Markdown 分隔用反引號 不上色；內容本身的字面反引號仍保留
    程式碼區塊 預設上色：Xcode／GitHub Light／VS2015 Dark；逐行 [div]＋等寬字體；空白行不包字體 可關閉上色；text 區塊維持單色，未知語言或超量時回退並提醒；請另存原始 Markdown
    HTML、LaTeX 公式 保留原文，顯示提醒 不執行 HTML、不渲染公式
